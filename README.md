# Expense Tracker (Трекер расходов)

**Автор:** Иванов Иван

## Описание программы

GUI-приложение на Python (Tkinter) для учёта личных расходов. Позволяет добавлять записи с указанием суммы, категории и даты, просматривать все расходы в таблице, фильтровать их по категории и диапазону дат, подсчитывать сумму расходов за произвольный период. Данные сохраняются в формате JSON и загружаются при следующем запуске. Встроена проверка корректности ввода.
