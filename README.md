# Expense Tracker (Трекер расходов)

**Автор:** Геращенко дмитрий Сергеевич

## Описание программы
Настольное приложение для учёта личных расходов с графическим интерфейсом. Позволяет добавлять записи о расходах (сумма, категория, дата), просматривать их в таблице, фильтровать по категории и периоду, а также автоматически вычислять сумму отфильтрованных трат. Данные сохраняются в JSON-файл и загружаются при следующем запуске.

## Основные функции
- Добавление новой записи расхода с валидацией (положительное число для суммы, формат даты ГГГГ-ММ-ДД).
- Отображение всех записей в виде таблицы.
- Фильтрация по категории (выпадающий список) и по диапазону дат.
- Подсчёт общей суммы расходов, соответствующих фильтру.
- Сохранение данных в файл `expenses.json` и автоматическая загрузка.
- Интуитивно понятный интерфейс на основе Tkinter.
